# Pilot outcome memo

## Overview of findings

We ran a pilot programme for automated intake triage between 10 January 2025 and 10 April 2025. The project tested whether software could process client requests faster than human staff. We deployed the tool across 3 departments to measure initial performance metrics. 

The software handled 450 client requests during the 3 months. System accuracy reached 88 percent for standard case categorisation. Staff members saved an average of 4 hours per week on administrative tasks.

## Operational impacts and next steps

The pilot exposed several operational bottlenecks in our current workflow. The intake software struggled with unstructured data inputs from legacy systems. Staff members spent extra time correcting misclassified files—a hidden cost that offset some initial time savings. 

We must address these technical limitations before we scale the software firm-wide. The pilot data shows clear financial benefits if we fix the integration errors (Smith, 2025). The total deployment cost reached USD 45,000 for the trial period.

We recommend the following actions:
* Upgrade the core database connectors
* Hire external developers for 2 weeks
* Retrain staff on new protocols
