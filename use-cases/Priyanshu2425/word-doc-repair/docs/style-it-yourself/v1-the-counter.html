You ask for a change in your own words, the counter answers in one ruled line, stamps it with a number, and offers to take it back. Ledger lines rather than speech bubbles — this build already keeps records, and a chat bubble would be a second visual language for the same act.

Notes

What it optimises
Trust. The person has already lost this file once; the counter never acts silently, numbers every change, and offers to put each one back before they have to ask.
The tape
One strip, at the top of the whole shell — the document is in our custody for as long as this screen is open. The sheet itself carries none, because it is the contents, not the custody.
The document is never smaller than the claim
The sheet takes 908 of 1320 px and scrolls independently. The counter is a rail, not a peer.
Refusals are visible
A red left rule, the same device the report uses for a loss. The counter says no in the same voice it says yes — the rule this build exists for.
When the counter is shut
No key, no allowance left, or SuperDocs unreachable: the rail renders one sentence saying so and the composer is not drawn at all. A step this copy of the page cannot take is never rendered as a button.
Both files stay reachable
The unstyled rebuild sits beside the download in the top bar the whole time, so preferring it never costs a second run.
