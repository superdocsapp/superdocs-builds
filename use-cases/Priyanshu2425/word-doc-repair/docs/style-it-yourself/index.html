Style it yourself

Five ways to put the person at the controls once the repaired document is ready — the file on one side, a line to SuperDocs on the other.

5 variationsdesktop 1320 × 840 and mobile 390 × 844 in each file26 August 2026

What is being designed

The recovery already styles the file on the way through, and hands the styled copy over with the plain rebuild still one link away. This adds a door after that: a person who does not like how their document has been set can say so, in their own words, and watch it change. Desktop is a split — the document on the left, the conversation on the right. On a phone the document holds the screen and the conversation is a drawer.

Where the door is

Beside the download, inside the panel that hands the file over — not on the report above it. The sentence has to say plainly that styling already happened, or the door reads as the opt-in button this build removed on 26 August.

The five

  • V1

    The Counter

    A clerk at the counter beside the desk. Ruled ledger lines rather than speech bubbles, every change numbered and stamped, and an offer to put each one back before it is asked for. Quick instruction chips under the field for the person with no vocabulary for what they want.

    Closest to today's page
  • V2

    Amendment Slips

    Every instruction becomes a numbered slip, newest on top, each revertible on its own without undoing the ones after it. Blue ticks in the document's margin show where each slip landed; hovering either one lights the other.

    Best when taste is being tried on
  • V3

    Margin Notes

    Point at the thing instead of describing it. Select a passage and the conversation attaches to it, so “smaller” is a complete instruction. Threads pinned to places rather than one transcript, and a rail that folds to a hairline for reading.

    Best for long documents
  • V4

    Proof Sheet

    The print shop: real pages in order with a thumbnail column, because styling changes where things fall. The rail is an order form that talks — each control writes a plain sentence into the field so you can see it, reword it, or ignore it and type your own.

    Best for people who know the result, not the words
  • V5

    Quiet Counter

    The least chat-like. One field, one sentence back, receipts one line each, and the full exchange behind a disclosure. The width a transcript would have taken goes to the sheet and to a toggle between how the file came back and how you have set it.

    Best for the document itself

True in all five

  • The document is never smaller than the claim about it. The sheet takes at least two thirds of the desktop width and the whole of the phone. The conversation is a rail, never a peer.
  • One strip of chevron tape, at the top of the shell. Tape means in our custody; the sheet itself carries none, because it is the contents rather than the custody.
  • The unstyled rebuild stays one click away for as long as the screen is open, so preferring it never costs a second run.
  • A refusal is said out loud, in red, and the page says what it cost. Asking for words the document does not have is refused before anything is sent, in the same voice a yes is given, and the allowance is untouched. A file thrown away because it came back wrong had already been charged for, and that line says so rather than claiming otherwise.
  • What is left is stated before it is spent — how many changes remain, on screen, next to the field that spends them.
  • Nothing renders as a button that cannot be pressed. No key, no allowance, or SuperDocs unreachable: the field is not drawn at all and one sentence says why. What already happened stays readable.

Against the baseline

B1, B2 and B4 hold. The styled file is still the deliverable, the plain rebuild is still reachable from the same panel, and nothing here runs during the recovery, so no failure in it can cost the recovery.

B3 needs the owner's eye. B3 says styling runs inside the recovery, with no opt-in button and no second request a person must know to make. This door opens after the automatic pass has already run and been handed over, so the invariant reads as still true — but the wording of the entry point is what keeps it true. “Style my document” would reintroduce the opt-in this build removed on 26 August. “Set it your way”, sitting under a sentence that says the file has already been styled, does not. That is a judgement about copy, and it is the owner's to make.

B5 extends rather than changes. Each change a person asks for is a stage like any other and belongs on the same progress line, as it happens, not summarised afterwards.
