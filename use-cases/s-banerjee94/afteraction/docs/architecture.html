The one rule

  • SuperDocs does the editing. This tool only decides what the document should say. It is built on top of SuperDocs, not a copy of it, so there is no second review screen.
  • Python picks the records. The model writes the sentence. If a model picked which 20 records out of 2,000 mattered, we could not explain why it dropped the rest.

Why the checks are cheap

  • Exporting is free. So we export after every turn and compare. We can show that nothing else changed instead of just saying so.
  • We check the finished file, not the instruction we sent. Checking our own instruction would prove nothing.

Where it fails

  • We check citations, not meaning. We can prove a sentence points at a real record. We cannot prove it describes that record correctly. That is what the person approving is for.
  • A crashed run starts over. If the server is busy we retry safely, but we cannot pick up a half-finished run from where it stopped.
