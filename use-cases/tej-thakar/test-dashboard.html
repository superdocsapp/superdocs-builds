What this build does: Takes raw resume text (messy, unstructured) and returns a clean, structured JSON record for each resume — full name, email, phone, skills list, work experience with dates, and education. Batch of 3 processed in one API call. All SuperDocs document edits happen server-side; the API returns the normalised schema. HITL gate auto-approved for bulk jobs.

Expected output: {"total": 3, "succeeded": 3, "failed": 0, "results": [...]} — each result has status "normalised" and a structured normalised object.
📋 Scenario:
Input — 3 Sample Resumes
Raw text resumes. Edit any field to try different inputs. The normaliser handles mixed formats, typos, and inconsistent date styles.

How to read the output
Each result in results[] has:
  • status: "normalised" — processed OK
  • normalised.full_name — cleaned name
  • normalised.email — primary email
  • normalised.skills[] — deduplicated skill list
  • normalised.work_experience[] — title, company, dates
  • normalised.education[] — degree, institution, year
Failed resumes have status: "error" and an error field — the batch still returns 200.

What this build does: Takes a document template with {{placeholder}} markers and a data record, fills every placeholder from the record, and shows [MISSING: field_name] for fields not present in the record. Pauses at a HITL gate — you review the filled document before it's finalised. The gaps list tells you exactly what was missing.

Expected output: Approve flow → {"status": "approved", "filled_text": "...", "gaps": ["approved_amount", "next_steps"]}. The two intentionally missing fields above will show as gap markers.
📋 Scenario:
Template + Record
The template has {{placeholders}}. The record has 5 of 7 fields. Two will intentionally become gap markers — watch for them in the output.

📝

Gap Markers
Missing fields become [MISSING: field_name] markers — visible in the filled document.

The gaps[] array in the response lists every field that wasn't in your record. Add those fields to the record and re-run to fill them.
