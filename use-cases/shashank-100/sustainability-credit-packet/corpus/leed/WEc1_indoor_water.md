# WE Credit: Indoor Water Use Reduction

**Rating system:** LEED v4.1 Building Design and Construction
**Category:** Water Efficiency
**Points available:** 1-6

## Intent

To reduce indoor water consumption.

## Requirements

Achieve the indoor water use reduction below the baseline calculated for the
building. The baseline is calculated using the fixture and fitting flow rates
listed in Table 1, applied to the estimated occupant usage groups for the
project. Reductions are demonstrated against this baseline using the actual
flow rates of the fixtures and fittings installed.

Points are awarded according to Table 2.

### Table 1. Baseline flow rates

| Fixture type          | Baseline flow rate      |
|-----------------------|-------------------------|
| Water closet          | 1.6 gallons per flush   |
| Urinal                | 1.0 gallons per flush   |
| Public lavatory faucet| 0.5 gallons per minute  |
| Private lavatory faucet| 2.2 gallons per minute |
| Kitchen faucet        | 2.2 gallons per minute  |
| Showerhead            | 2.5 gallons per minute  |

### Table 2. Points for indoor water use reduction

| Percentage reduction from baseline | Points |
|------------------------------------|--------|
| 25%                                | 1      |
| 30%                                | 2      |
| 35%                                | 3      |
| 40%                                | 4      |
| 45%                                | 5      |
| 50%                                | 6      |

All newly installed toilets, urinals, private lavatory faucets and showerheads
that are eligible for labeling must be WaterSense labeled.

## Required documentation

1. A fixture and fitting schedule listing every installed fixture type, its
   manufacturer, model, and rated flow rate.
2. The indoor water use calculation showing baseline consumption, design
   consumption, and the resulting percentage reduction.
3. Manufacturer cut sheets or WaterSense certificates for each fixture type.
4. The occupancy assumptions used in the calculation.
