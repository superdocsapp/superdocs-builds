# Acme Corporation — Politique d'équipement pour le télétravail

## Objet
Cette politique explique comment les employés peuvent demander le remboursement du matériel de bureau à domicile. Elle s'applique à tous les employés à distance à temps plein.

## Plafond de remboursement
Les employés peuvent être remboursés jusqu'à 800 $ par année civile pour du matériel de bureau à domicile approuvé.

## Délai de soumission
Les reçus devraient être soumis dans un délai de 14 jours suivant l'achat pour être admissibles au remboursement.

## Approbation
L'équipe des finances examinera et approuvera les demandes admissibles dans un délai de cinq jours ouvrables.
