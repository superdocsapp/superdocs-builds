# Tariff Classification Memo Builder Examples

This directory contains representative example fixtures for the **Tariff Classification Memorandum Builder** use case in DocIntel.

## Contents

1. **aerolink_x7_product_specification.pdf**:
   - Sample input technical document describing the **AeroLink X7 Industrial IoT Wireless Transceiver**.
   - Includes physical dimensions, wireless specifications, antenna arrays, operating frequencies, and environmental ratings.

2. **thermotrack_customs_ruling.pdf**:
   - Sample US Customs & Border Protection (CBP) ruling document (**HQ H312450**) establishing precedent for dual-mode industrial communication equipment.

3. **aerolink_x7_product_image.png**:
   - High-resolution product schematic and diagram embedded into the canonical generated memorandum.

4. **aerolink_x7_tariff_classification_memo.docx**:
   - The complete, canonical generated Tariff Classification Memorandum in Microsoft Word (.docx) format.
   - Features structured sections:
     - Executive Summary
     - Product Overview & Technical Analysis
     - Applicable Legal Notes & General Rules of Interpretation (GRIs)
     - Harmonized Tariff Schedule (HTSUS) Heading Analysis (8517.62 vs 8517.69)
     - Customs Rulings & Precedent Comparisons
     - Final Recommended Classification & Duty Rate
     - Verified Citations & Lineage Metadata
