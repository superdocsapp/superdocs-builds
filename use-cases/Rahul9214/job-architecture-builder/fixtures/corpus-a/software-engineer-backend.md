# Software Engineer, Backend

## Team
Platform Services

## Role purpose
Build and maintain the service APIs that other Northstar product teams use for identity, entitlements, and workspace metadata.

## Responsibilities
- Design, implement, and operate backend services written in Go and PostgreSQL.
- Own on-call for the services you ship, including incident response and post-incident write-ups.
- Review pull requests for API contracts, data-model changes, and failure handling.
- Add observability: structured logs, metrics, and traces that on-call engineers can actually use.
- Partner with product engineering teams to version APIs without breaking existing clients.
- Improve test coverage for authorization edge cases and multi-tenant isolation.

## Scope and autonomy
You own two to three services used across several product lines. Technical choices inside those services are yours, within published platform standards. Cross-service interface changes need a short design review with the staff engineer on the team. You do not set org-wide architecture.

## Leadership and management
No direct reports. You mentor newer engineers through code review and pairing. You may lead a small project (a few weeks) when a service needs a migration.

## Stakeholders
- Product engineering teams that consume platform APIs
- Site reliability engineers who share on-call rotations
- Security reviewers for tenant isolation changes
- Your engineering manager for priorities and performance

## Requirements
- Experience building production HTTP services and relational data models.
- Comfort with code review, automated testing, and production debugging.
- Clear written communication for design notes and incident summaries.
