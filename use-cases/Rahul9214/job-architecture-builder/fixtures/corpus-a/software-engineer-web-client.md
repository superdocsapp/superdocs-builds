# Software Engineer, Web Client

## Team
Product Engineering

## Role purpose
Implement user-facing web features for Northstar's workspace product in close partnership with design and product.

## Responsibilities
- Build React interfaces from accepted design specs and product briefs.
- Hook UI flows to existing backend APIs; flag contract gaps rather than inventing new services.
- Write component and integration tests for the flows you own.
- Fix visual and accessibility defects reported by design or QA.
- Participate in sprint planning and estimate your own tickets.
- Keep the design-system usage in your features consistent with published components.

## Scope and autonomy
You work within a single product surface. Ticket scope is usually days, not months. You choose implementation details inside a component, but routing, state libraries, and API shapes are already decided by more senior engineers. Production releases go through the team's existing checklist.

## Leadership and management
No direct reports. You are not expected to run projects for other engineers. You may pair with an intern or new hire when asked.

## Stakeholders
- Product manager for workspace
- Product designer for the same squad
- Backend engineers who own the APIs you call
- QA for release sign-off
- Your engineering manager

## Requirements
- Experience building production web applications with a modern component framework.
- Familiarity with accessibility basics and responsive layout.
- Willingness to work from design files and written acceptance criteria.
- Collaborative debugging with backend and QA partners.
