Retrieval-augmented generation (RAG) is an architecture that pairs a large language model with an external retrieval system, allowing the model to consult a document collection at inference time rather than relying solely on knowledge encoded in its parameters. In a typical RAG pipeline, an incoming query is first converted into a dense vector embedding, which is then compared against embeddings of pre-indexed document chunks using approximate nearest-neighbor search. The most relevant chunks are retrieved and inserted into the model's context window alongside the original query, giving the model concrete source material to ground its response in.

The primary motivation for RAG is reducing hallucination: language models trained purely on next-token prediction can generate fluent but factually incorrect statements, especially about specialized or rapidly changing domains. By supplying retrieved passages as grounding evidence, RAG systems can produce responses that are traceable back to specific source documents, which is particularly valuable in domains like legal research, medical question answering, and enterprise knowledge management where factual accuracy and auditability matter.

RAG also offers a practical advantage over full model retraining: updating the knowledge base only requires re-indexing the document collection, not fine-tuning the underlying model. This makes RAG systems easier to keep current as source material changes, and allows the same base model to be deployed across many different knowledge domains simply by swapping the retrieval index.
