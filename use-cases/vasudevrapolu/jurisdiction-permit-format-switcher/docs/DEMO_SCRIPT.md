# 3-minute demo script

## 0:00–0:20 — Problem

"This is a synthetic solar project. The coordinator enters it once. The problem is that each authority expects a different permit packet."

## 0:20–1:20 — Assigned build

1. Show the project record.
2. Generate Sunvale.
3. Point out forms, plan notes, attachments and signatures.
4. Remove the license number and generate again.
5. Show the explicit blocking gap instead of a blank field.
6. Switch to Ridgefield without changing the project record.
7. Point out the different form set and fire/storage/structural requirements.

## 1:20–2:30 — Task 1 agentic system

1. Open Agentic System tab.
2. Run synthetic corpus.
3. Show visible stages.
4. Show compliance finding waiting at human review.
5. Explain that source instructions are treated as data.
6. Mention persisted run state and machine-readable approval endpoint.

## 2:30–3:00 — Engineering choices

"Jurisdiction differences are configuration, not conditionals. The API key is server-side. The workflow has a human gate, resumable state, concurrency-safe run IDs, deterministic tests without a live key, and an MCP tool surface. The remaining live step is the candidate-account SuperDocs round-trip."
