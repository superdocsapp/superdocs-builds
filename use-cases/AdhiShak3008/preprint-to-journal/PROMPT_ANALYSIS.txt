=========================================
ISSUE-BY-ISSUE ANALYSIS
=========================================

ISSUE 1 — Abstract heading disappeared
---------------------------------------
Root cause: The SCIENCE_PRESERVATION_PREAMBLE says "The transformation changes
only document structure, section order, reference formatting style, and placement
of figures and tables." It does NOT explicitly say "preserve all existing
headings". Section 1 says "Rename existing sections to match these headings
exactly" — but if SuperDocs interprets the Abstract as a special preamble block
rather than a named section, it may strip the heading while keeping the text.
The notes field also says "Abstract is unstructured (no subheadings)" which
SuperDocs may have misread as "the Abstract block has no heading".

What is missing: An explicit rule that says the "Abstract" heading must be
present as a visible section heading in the output, and that "unstructured"
refers only to the absence of sub-headings within the abstract body, not the
absence of the "Abstract" heading itself.


ISSUE 2 — Section order became Introduction → Results → Discussion → Methods
------------------------------------------------------------------------------
Root cause: Section 1 of the prompt says "Reorganise the manuscript so its
sections appear in this exact order" and lists the correct Nature order. However
the notes field at the end says:

  "Methods section appears after Discussion, not before Results."

This note is redundant with the section_order list (Methods is already listed
after Discussion), but more importantly it is phrased as a clarification, not
a hard constraint. SuperDocs may have treated the notes as the authoritative
instruction and the numbered list as a suggestion, or it may have matched the
note's phrasing ("after Discussion") without reading the full list.

Additionally, the section order instruction uses the word "Reorganise" which is
a soft verb. There is no explicit statement that the order is mandatory and
non-negotiable.

What is missing: The section order must be stated as a hard, non-negotiable
constraint. The redundant note about Methods placement should be removed from
the notes field (it is already encoded in section_order). The instruction should
say explicitly: "This order is mandatory. Do not deviate from it."


ISSUE 3 — SuperDocs invented an Author Contributions statement
---------------------------------------------------------------
Root cause: This is the most serious issue. Section 6 of the prompt says:

  "If it is missing, insert a placeholder section with the text
   '[DECLARATION REQUIRED — please complete before submission]'"

SuperDocs did not insert that placeholder. Instead it fabricated a realistic-
looking Author Contributions statement ("A.K. conceived and designed the
experiments..."). This means SuperDocs ignored the placeholder instruction and
generated content from its own knowledge of what such a statement looks like.

The current preamble prohibits altering "scientific claims, numerical results,
statistical values, equations, or the meaning of any citation." It does NOT
explicitly prohibit inventing author contribution statements, funding
information, affiliations, or other factual metadata. SuperDocs found a gap
in the prohibition and filled it.

What is missing: An explicit, prominent prohibition on inventing any factual
information — author contributions, funding sources, affiliations, dates,
copyright, publication metadata — not just scientific data. The placeholder
instruction must be strengthened: "Do NOT generate a contribution statement.
Do NOT fill in author names, roles, or any other information. Leave the section
heading only with no body text, or omit the section entirely."


ISSUE 4 — SuperDocs added copyright/publication boilerplate
------------------------------------------------------------
Root cause: There is no rule in the current prompt that prohibits adding
publication metadata, copyright notices, or institutional boilerplate. The
closing line says "do not add any commentary or explanation inside the document
body" — but SuperDocs apparently classified the copyright line as document
metadata rather than commentary, so the rule did not fire.

The SCIENCE_PRESERVATION_PREAMBLE only protects scientific content. It says
nothing about non-scientific additions.

What is missing: An explicit rule that prohibits adding any content that was
not present in the source manuscript — specifically: copyright notices,
publication dates, journal names, DOIs, institutional affiliations, ISSN/ISBN,
editor names, submission/acceptance dates, or any other publication metadata.
The rule must be framed as "do not add anything that is not in the source",
not just "do not add commentary".


ISSUES 3 & 4 — Shared root cause
----------------------------------
Both issues share the same underlying gap: the no-fabrication constraint in
the preamble is scoped only to scientific content (numbers, equations,
citations). It does not cover factual metadata. SuperDocs is a capable model
and will helpfully fill in "missing" information unless explicitly told not to.
The fix is to broaden the no-fabrication rule to cover ALL factual content,
and to make it the very first and most prominent constraint in the prompt.

   confidence intervals, effect sizes, sample sizes), equations, or the meaning

   appear in the output exactly as it appears in the input.
