# Sample output

Produced by a real run against `api.superdocs.app`, committed as raw data so the claims
in the top-level README can be checked rather than taken on trust.

| File | What it is |
|---|---|
| `migration-commitments.json` | every candidate the extraction produced, including the four it refused and why |
| `migration-letter.txt` | the text of the exported `.docx`, showing which two commitments made it in |
| `migration-reply-draft.eml` | the draft reply, threading headers and all — open it in a mail client |
| `nothing-was-agreed.md` | what it writes when a thread contains no commitments at all |
| `nothing-commitments.json` | the empty evidence file for that thread |

Every person, company and thread here is invented.
