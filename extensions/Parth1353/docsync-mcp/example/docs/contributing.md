# Contributing to the provisioning service

*Synthetic example document for the docsync extension.*

This document has no `docsync` block in its front matter, so docsync does not
manage it and will never propose an edit to it. That is the default: dropping
this tool into a docs tree does nothing at all until somebody opts a document
in by declaring what it covers.

It is here so the example has at least one document that is deliberately left
alone, and so `docsync audit` has something to be quiet about.

## Running the tests

```bash
pytest -q
```

## Style

Write the reason, not the rule. A runbook that says what to do and not why
stops being followed the first time reality differs from it.
