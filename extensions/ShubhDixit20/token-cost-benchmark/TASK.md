# TASK.md

What this repository is: my SuperDocs Round 2 submission — assigned build
(Task 2), "Token-cost benchmark: whole-document regeneration against
section-level editing."

## Layout

```
benchmark/       the harness itself (corpus generation, edit tasks, the two
                 arms, client abstraction, runner, report generator)
tests/           offline tests, no live API key required
data/corpus/     generated synthetic documents (regenerated by the runner;
                 committed so results are reproducible without re-running)
data/results/    raw_edits.csv/json + summary tables + charts (committed —
                 "raw data committed" is one of the card's bars for strong)
scripts/         (reserved; currently empty — the CLI lives in
                 benchmark/runner.py and benchmark/report.py)
run.sh           one-command reproduction
```

## How to work with this

- `./run.sh` runs tests, then the full mock-mode benchmark, then builds
  reports. That's the one command a stranger needs.
- Mock mode is the default and costs nothing (see README "Budget guard").
  Real-API mode is opt-in via `--mode real` and a live `SUPERDOCS_API_KEY`.
- Every non-obvious call I made is logged in PROGRESS.md as I made it, not
  reconstructed after the fact.
