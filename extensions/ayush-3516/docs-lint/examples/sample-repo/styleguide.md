# House style guide

This is the file docs-lint consults. It is data, not code: edit it, or replace it with your own,
and the linter changes with it. Nothing in the tool needs to know these rules in advance.

## Words

- Prefer plain words. Do not write "utilise" or "leverage" where "use" works.
- Do not write "in order to". Write "to".
- Do not write "a large number of". Write "many".

## Headings

- Headings use sentence case. Only the first word and proper nouns are capitalised.
- Headings do not end in a full stop.

## Code

- Every fenced code block declares its language, so it highlights correctly.

## Voice

- Address the reader as "you".
- Prefer the active voice. Say what does the thing.
