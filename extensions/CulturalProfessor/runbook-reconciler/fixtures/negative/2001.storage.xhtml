When this fires

The PaymentsApiHighLatency alert fires when p99 request latency stays above 1200ms over a 5-minute window, and only after it has held for 10 minutes.

Everything on this page is correct. It is written in milliseconds because that is what the payments team thinks in; the alerting rule stores the same number in seconds.

Triage

The deployment is payments-api in namespace payments, and it runs 6 replicas.

Start at the Payments overview dashboard and look at the p99 panel before touching anything.

Mitigation

If a bad release is the cause, run the manual-rollback job in the deploy workflow. It reverts production to the previous image.

Escalation
