When this fires

The PaymentsApiHighLatency alert fires when p99 request latency for payments-api stays above 800ms for 10 minutes.

Dashboard: Payments overview. Severity is critical and it pages immediately.

Triage

Start with pod health. The deployment is payments-api in namespace payments, and it runs 6 replicas.

bash

If pods are healthy, check the read replica. Slow reads against meridian-payments-prod-replica are the usual cause of a latency spike with a flat error rate.

Mitigation

Restart the deployment first — it clears a wedged connection pool without a release:

bash

If a bad release is the cause, re-run the rollback-production job in the deploy workflow. It needs a production environment approval, so find a second reviewer before you start.

Escalation

Page the Payments Core rota if latency stays above the threshold for 30 minutes, or immediately if checkout is failing.
