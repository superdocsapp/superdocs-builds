# A Map That Says So

The argument of this book is small and I will state it plainly.

A map should record how it knows what it claims.

Not in a legend nobody reads, and not in metadata that survives one format migration
and then does not. On the face of the sheet, in the same ink as the features: this
line was walked in 2019, this line was walked in 1971, this line has never been walked
by anyone now living.

![[Figures/correction-notice.png|The 2021 correction notice for Sheet 4, which removes the Cowley Bottom path in a single line of eight-point type.]]

We already know how to do this. Geological maps have carried confidence boundaries for
a century. Bathymetric charts distinguish surveyed from interpolated depth. The
technique is not the obstacle.

## The obstacle

The obstacle is that a map which admits what it does not know is a worse product, in
the narrow commercial sense, than one that does not. It is uglier, it is harder to
read, and it invites the question of why you are charging full price for a sheet with
holes in it.

That is the cartographer's dilemma, and I do not think it resolves. But I notice that
the National Survey Office's own revision policy [@ordnance2019] already contains the
distinction internally, in the field that records the evidence class for each feature.
The information exists. It is simply not printed.

Print it.
