# Three-minute demo

1. **0:00–0:20** Create a run for the synthetic Q3 release bundle.
2. **0:20–0:45** Upload the requirements and test evidence; show the stage timeline.
3. **0:45–1:15** Open a finding and click through to its filename, SHA-256, line, and quote.
4. **1:15–1:40** Show the contradictory evidence and missing-evidence blocker.
5. **1:40–2:05** Reject one finding with feedback and approve another; unresolved items keep the run pending.
6. **2:05–2:30** Upload the incremental evidence file and show the new report revision and changed finding IDs.
7. **2:30–2:50** Demonstrate interruption injection and resume from the saved stage checkpoint.
8. **2:50–3:00** Show the final verdict, stage metrics, citations, and JSON report.

Run the deterministic script with `python3 scripts/demo.py` after installing backend requirements.
