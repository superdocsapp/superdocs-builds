Meridian SDK — API reference

The Meridian SDK is a small client for the Meridian ledger service. This page documents the public surface.

Configuration

The client accepts a number of module-level defaults. The default request timeout is 45 seconds, which is generous for most workloads. The maximum page size is 500 records. Requests are issued against the eu-west-1 unless another is given.

Client

Construct a client with your API key. The constructor also accepts region, timeout and max_retries, which defaults to 3.

list_ledgers

Returns a list of dictionaries, newest first. Pass page_size to control how many come back; it defaults to 100. A cursor may be supplied to continue a previous page, and include_archived pulls in ledgers that have been archived.

If page_size is larger than the maximum, the call raises ValueError.

get_ledger

Fetches a single ledger by id and returns a dictionary. Raises NotFound when no such ledger exists.

post_entry

Appends an entry to a ledger and returns the created entry as a dictionary. Amounts are given in minor units, so 1250 means 12.50. The currency argument defaults to EUR. Pass an idempotency_key to make retries safe.

close_ledger

Closes a ledger and returns a boolean. A ledger_id and reason are required.
